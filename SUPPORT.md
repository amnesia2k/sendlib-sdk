# Support

Use [GitHub Issues](https://github.com/amnesia2k/sendlib-sdk/issues) for reproducible SDK bugs, type problems, documentation corrections, and feature proposals. Include the SDK version, Node version, module format, a sanitized example, the actual result, and the expected result.

Do not post API keys, authorization headers, personal addresses, message bodies, attachments, or unsanitized upstream responses. Report vulnerabilities through [SECURITY.md](./SECURITY.md).

This is an unofficial community SDK. SendLib account connections, Gmail authorization, quotas, billing, dashboard templates, delivery incidents, and API availability belong with [SendLib's official documentation and support](https://sendlib.samueltuoyo.com/docs).
